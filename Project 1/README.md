\# CCNA Networking Project



\## Project Overview

This project was created using Cisco Packet Tracer to practice fundamental networking concepts.



\## Technologies and Concepts

\- Cisco Packet Tracer

\- IP Addressing

\- VLANs and Trunking

\- DHCP Configuration

\- Network Connectivity Testing



\## Project Objectives

\- Practice network device configuration.

\- Understand basic switching and network connectivity.

\- Configure and troubleshoot DHCP.

\- Verify connectivity using ping and other network commands.



\## Testing

Network connectivity and DHCP operation were tested in Cisco Packet Tracer.
